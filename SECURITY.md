# Security policy

PhotoLine shows people's private photos, so security reports are handled first.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately on GitHub instead: open the repository's **Security** tab
and choose **Report a vulnerability**
(<https://github.com/rumcajz/photoline/security/advisories/new>). Only the
maintainer sees the report.

Please include the PhotoLine and ownCloud versions, the steps to reproduce and
what an attacker could gain (for example: see another user's thumbnails, reach
a route without logging in).

You will get an answer within a few days. Confirmed problems are fixed in a new
release on the ownCloud Marketplace, and the advisory is published once the fix
is available.

## Supported versions

Only the latest release receives security fixes.
